# Casos Reais da Franquia

Projeto que visa compartilhar experiências reais dos técnicos e transformar os aprendizados dos atendimentos em melhorias para toda a equipe.

## Objetivo

Utilizar casos reais para:
   * Desenvolver raciocínio técnico;
   * Melhorar a postura no atendimento ao cliente;
   * Compartilhar experiências entre os técnicos;
   * Identificar formas de evitar problemas recorrentes;
   * Melhorar os processos da Franquia
    
## Reuniões

**Quando:** Todas as quartas-feiras

**Duração:** 1 hora

Cada reunião será baseada em experiencias que o técnico Vinicius teve em João Pessoa na Matriz.

**Estrutura**

   1. **Apresentação de Caso**
   2. **O que você faria?**
   3. **Como o caso foi resolvido**
   4. **Debate com a equipe**
   5. **Lições aprendidas**
   6. **Aplicação pratica**

## Temas

Os casos podem abordar:
  * Implantação;
  * Atendimento ao cliente;
  * Suporte N1/N2;
  * Diagnostico de problemas;
  * Infraestrutura;
  * Fiscal;
  * Parametrização;
  * Organização dos processos;
  * Experiências com clientes;
  * Novidades e melhorias do sistema.
    
## Principio

> **Não é uma reunião para apontar erros. É uma reunião para aprender com situações reais e melhorar a forma como trabalhamos.**

## Primeiro caso

**Como conduzir uma implantação quando o cliente quer manter uma prática incorreta.**

Caso baseado na experiência da implantação do Gran Forneria durante a imersão em João Pessoa.
