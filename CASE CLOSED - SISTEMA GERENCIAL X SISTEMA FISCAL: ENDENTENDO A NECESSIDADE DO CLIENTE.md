# Sistema Gerencial x Sistema fiscal: entendendo a necessidade do cliente

**Objetivo:**

Desenvolver a capacidade dos técnicos de enteder a necessidade real do cliente e identificar a importancia de separar as funções de controle gerencial e as obrigações fiscais dentro da operação.

**Por que este tema é importante:**

O cliente pode utilizar sistemas diferentes para atender necessidades diferentes. O técnico precisa enteder que o sistema fiscal não necessariamente atende todas as necessidades de gestão da empresa, assim como um sistema gerencial não sustitui as obrigações fiscais.

O papel do técnico é enteder a operação do cliente e identificar qual solução atende melhor cada necessidade.

## 1. Apresentação do caso

No final/inicio do ano, tivemos o caso de **Imperial Madeiras**.

O cliente já utilizava um sistema, porém ele não atendia adequandamente às necessidades da empresa, principalmente em relação ao **controle de estoque**.

Um dos problemas identificados era que o cliente realizava compras de determinados produtos sem nota fiscal.

Isso gerava uma dificuldade para manter um controle adequado do estoque dentro do sistema que utilizavam.

**Perguntas para a equipe**
    * Qual é o principal problema apresentado nesse caso?
    * O problema esta necessariamente relacionado à emissão fiscal?
    * O que o cliente precisa realmente controlar?
    * Como vocês explicariam para o cliente a diferença entre o controle gerencial e o controle fiscal?
    * Um único sistema precisa necessariamente atender todas as necessidades da empresa?
    * Como identificar se o problema do cliente é de sistema ou de processo?
    
## 2. Entendo os dois sistemas

Nesse caso, é importante compreender que existem **necessidades diferentes dentro da operação do cliente.**

**Sistema Gerencial**

Está relacionado ao controle da operação da empresa, como:

* Estoque;
* Compras;
* Vendas;
* Financeiro (Contas a pagar e a receber);
* Informações para gestão.

**Sistema Fiscal**

Está relacionado ao cuprimento das obrigações fiscais e à emissão dos documentos necessários para as operações da empresa.

O ponto principal é enteder que **controle gerencial e controle fiscal possuem objetivos diferentes,** mesmo que estejam relacionados.

## 3. O caso de Imperial Madeiras

O sistema utilizado anteriormente pelo cliente não atendia adequandamente à necessidade de controle de estoque e gestão da empresa.

A situação ficava ainda mais complicada porque o cliente realizava compras de produtos sem nota fiscal.

Isso exigia que o sistema fosse capaz de representar corretamente a realidade da operação para que o cliente tivesse controle sobre sua empresa.

**Perguntas para o debate**
    * O cliente está procurando apenas um sistema para emitir nota documentos fiscais?
    * **Qual é a importancia de entender o sistema fiscal e o gerencial?**
    * **Como explicar ao cliente que ele deve utilizar os dois sistemas?**
    * Quais os riscos existem quando o cliente somente o sistema fiscal?
    
## 4. Debate

**Perguntas para a equipe**
    * Quando um cliente diz que precisa de "um sistema", o que devemos perguntar antes de apresentar a solução?
    * Como identificar as prinpais necessidades do cliente?
    * Quais informções devemos levantar sobre estoque, compras e vendas?
    * Como diferenciar uma necessidade gerencial de uma necessidade fiscal?
    * Até que ponto devemos adaptar o sistema ao processo do cliente?
    * Quando devemos orientar o cliente a mudar um processo em vez de tentar adaptar o sistema?
    
## 5. Lições Aprendidas

**Principais aprendizados**
    * Antes de apresentar a solução, precisamos enteder como o cliente trabalha;
    * O tecnico deve identificar a necessidade real por trá da solicitação do cliente;
    * Sistema gerencial e sistema fiscal possuem objetivos diferentes;
    * A implantação precisa considerar a realidade operacional do cliente;
    * Nem sempre o problema está no sistema; pode existir um problema no proprio processo da empresa;
    * Quanto melhor entendermos a operação do cliente, maior será nossa capacidade de indicar e configurar a solução adequada.
